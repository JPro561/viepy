What it's viepy?

Viepy (or simply vie) is a simple library made for people who want to create music videos without spending any money. It's free and easy to use.

Requirements

To install the viepy library you need to have:

  • Python 3.11 or newer;
  • FFmpeg installed in your PATH (or in your environment variable);
  • Basic knowledge of Python.

Simply. Just that. Then, if you don't know nothing of the library, check the Get Started page.
