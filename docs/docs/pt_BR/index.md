## O que é o Viepy?

Viepy, ou simplesmente `vie`, é uma biblioteca simples para criar videoclipes e visualizadores com Python. É de graça e fácil de usar.

### Requisitos

Para instalar e usar o Viepy, você precisa do:

* [Python 3.11](https://www.python.org/downloads/) ou mais novo;
* [FFmpeg and FFprobe](https://ffmpeg.org/) instalado e acessível no seu `PATH`;
* Uma noção básica de [Python](https://www.python.org/).

*<small>Mais informações sobre instalar o Viepy [aqui](getting_started/installation.md).</small>

Então, crie seu primeiro vídeo seguindo o [Guia "Começando"](getting_started/first_video.md).

E é isso! Você está pronto para criar com o Viepy!
